# Dataset del clasificador aviar

Crea estas carpetas y coloca imagenes JPG, PNG o WEBP en cada una:

```text
train/
  garza-azul/
  pelicano-peruano/
  cormoran/
  gaviota/
  playerito/
  not_bird/
validation/
  garza-azul/
  pelicano-peruano/
  cormoran/
  gaviota/
  playerito/
  not_bird/
```

Usa fotografias variadas: angulos, fondos, tamanos, iluminacion y distancia.
`not_bird` debe incluir jirafas, llamas, otros mamiferos, personas, paisajes y objetos.
No mezcles la misma fotografia entre `train` y `validation`.
